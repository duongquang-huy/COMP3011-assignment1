# COMP3011-assignment1
A Spring Boot web application that records audio from the browser microphone and converts it into text using the OpenAI Speech-to-Text API.
## Features
- Record audio using the browser microphone
- Convert speech to text
- Java Virtual Threads for concurrent requests
- Track token usage
- Secure API key using an OS variable
- Server uptime and shutdown endpoints

- **Frontend:** HTML + JavaScript
- **Backend:** Spring Boot REST API
- **API:** OpenAI Speech-to-Text API
